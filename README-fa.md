# سامانه فرم‌ساز مرکزی دانش‌آموزی

این پروژه نسخه چنددستگاهی فرم‌ساز مدرسه است که فرم و پاسخ‌ها را به‌جای `localStorage` در MySQL/MariaDB ذخیره می‌کند.

## فناوری

- HTML5
- CSS3 Responsive
- JavaScript بدون فریم‌ورک
- PHP 8.1+ با PDO
- MySQL 5.7+/8.x یا MariaDB سازگار

## امکانات اصلی

- فرم‌ساز کامل مدیر
- دسترسی مدیر از لپ‌تاپ، تبلت و گوشی
- Draft مرکزی و Publish واقعی
- نسخه‌بندی فرم‌ها
- حفظ پاسخ‌های قدیمی در کنار نسخه فرم مربوطه
- نمایش فرم منتشرشده روی همه دستگاه‌ها
- شرط‌های متعدد با AND / OR
- شرط‌های `eq`, `neq`, `contains`, `starts`, `ends`, `empty`, `notempty`
- جلوگیری از شرط به سؤال آینده
- جلوگیری از ایجاد وابستگی شکسته هنگام جابه‌جایی سؤال
- حذف وابستگی‌های شرطی هنگام حذف سؤال مرجع
- اعتبارسنجی سمت مرورگر و سمت سرور
- تاریخ شمسی و تقویم شمسی
- سریال شناسنامه با حرف + دو رقم / شش رقم
- شماره موبایل و اعتبارسنجی Regex
- معدل با بازه ۰ تا ۲۰
- کنترل تعداد فرزندان و ترتیب فرزند
- Auto Next
- JSON Import / Export
- JSON Export پاسخ‌ها
- Excel XLSX Export بدون کتابخانه خارجی
- جست‌وجوی پاسخ‌ها
- صفحه‌بندی پاسخ‌ها
- حذف یک پاسخ یا همه پاسخ‌ها
- ویرایش پاسخ ذخیره‌شده توسط مدیر
- تغییر رمز مدیر
- Password Hash
- Session امن و CSRF برای عملیات مدیریتی
- محدودسازی تلاش‌های ناموفق ورود
- ثبت Audit Log عملیات مدیر
- ذخیره واقعی مرکزی در دیتابیس
- ذخیره موقت فقط Theme و نام دستگاه در مرورگر؛ هیچ داده اصلی فرم/پاسخ در `localStorage` ذخیره نمی‌شود.

## نصب روی هاست

1. محتویات پروژه را روی هاست دارای PHP و MySQL/MariaDB قرار دهید.
2. مطمئن شوید PHP حداقل نسخه 8.1 داشته باشد.
3. `install.php` را در مرورگر باز کنید.
4. اطلاعات دیتابیس و حساب مدیر را وارد کنید.
5. نصب‌کننده دیتابیس، جدول‌ها، مدیر و فرم اولیه را ایجاد می‌کند.
6. پس از موفقیت نصب، فایل `install.php` را حذف کنید.
7. برای فرم عمومی به `index.php?mode=form` بروید.
8. برای پنل مدیر به `index.php?mode=admin` بروید.

## جریان استفاده

### مدیر

مدیر از هر دستگاه وارد `mode=admin` می‌شود و همان Draft مرکزی را می‌بیند.

- تغییر فرم → ذخیره پیش‌نویس
- انتشار → ساخت نسخه جدید Published
- همه دستگاه‌ها → نسخه جدید Published

### دانش‌آموز

دانش‌آموز با گوشی یا لپ‌تاپ `mode=form` را باز می‌کند.

فرم همیشه بر اساس آخرین نسخه Published دریافت می‌شود.

### پاسخ‌ها

پاسخ هر ثبت به `form_version_id` متصل است؛ بنابراین اگر فرم بعداً تغییر کند، ساختار پاسخ‌های قبلی حفظ می‌شود.

## نکات مهم امنیتی

- فایل `config.php` حاوی رمز دیتابیس است و باید توسط وب‌سرور قابل دانلود نباشد.
- فایل `install.php` پس از نصب باید حذف شود.
- حتماً سایت را روی HTTPS اجرا کنید.
- برای محیط واقعی مدرسه، بکاپ دوره‌ای MySQL تنظیم کنید.
- برای استفاده عمومی گسترده، Rate Limit و CAPTCHA را می‌توان به endpoint ثبت پاسخ اضافه کرد.

## تست محلی

برای تست رابط کاربری می‌توان از PHP Built-in Server استفاده کرد، اما برای ذخیره واقعی باید MySQL/MariaDB فعال باشد:

```bash
php -S 127.0.0.1:8000
```

سپس:

```text
http://127.0.0.1:8000/install.php
```

### اگر هاست اجازه ساخت دیتابیس نمی‌دهد

ابتدا دیتابیس و کاربر MySQL را از پنل هاست بسازید، سپس همان نام دیتابیس، نام کاربری و رمز را در `install.php` وارد کنید. اگر هاست نام دیتابیس را با پیشوندی مثل نام حساب شما می‌سازد، همان نام کامل را وارد کنید.
